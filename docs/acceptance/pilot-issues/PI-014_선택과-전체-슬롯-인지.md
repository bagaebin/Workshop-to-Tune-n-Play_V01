## 관찰

- 노트를 고르고 길이를 바꾸는 방법, 지금 무엇을 하고 있는지 알 수 없다
- 탭으로 선택·해제된다는 것을 알 수 없다
- 전체 슬롯의 그림이 "전체 선택"이라는 것을 알 수 없다

PI-007에서 선택 테두리를 넣은 빌드(`043b778`)에서의 관찰이다 — 테두리만으로는 부족했다.

## 판단

N5가 창작 기능에 글자를 금하므로 뜻은 **미리보기와 반응**으로만 전달된다. 지금 상태:

| 기능 | 지금 전달 수단 | 약한 곳 |
| --- | --- | --- |
| 선택 | 탭하면 흰색 + 테두리 · 소리 1회 | 새 노트를 놓으면 그것이 자동 선택이라 **선택이 "항상 켜진 것"처럼** 보인다. 탭이 토글인지 드러나지 않는다 |
| 길이 조정 | 노트 오른쪽 끝을 끈다 | 손잡이 표시가 없다 |
| 전체 | 미리보기 — 흩어진 점이 한꺼번에 밝아짐 | 누른 뒤 면 위 노트가 전부 테두리로 바뀌는 반응은 있으나, 노트가 없을 때 누르면 아무 변화가 없다 |

| 안 | 내용 |
| --- | --- |
| A | 그대로. 회고에서 묻는다 — *"왼쪽 아래 이것들 눌러 보셨어요?"*. 미사용 목록이 회고 시트에 나온다 |
| B | 표시만 보강 — 선택된 노트의 오른쪽 끝에 길이 손잡이 표시 · 선택 해제 시 테두리가 사라지는 짧은 전환 |
| C | 과제문 전 튜토리얼을 늘린다 — N5 · G13과 충돌. 권하지 않는다 |

B는 표시만 바꾸므로 로그와 분석에 영향이 없다.
