## 관찰

사용자 — *"마킹 버튼을 눌러도 아무 반응이 없어 마킹이 정상적으로 진행되었는지 알 수 없다."* TEST3 로그 — `slot:mark` 1회, `snapshot s1` · `mark {n_before:17}` 정상 기록.

## 판단

설계대로다. G10 규칙 3의 취지는 **누른 것을 도구가 보상하지 않는다**(K3)이다. 그런데 *눌림 확인*과 *보상*은 다르다 — 버튼이 눌렸다는 신호가 없으면 참여자는 고장으로 읽거나 다시 누른다.

| 안 | 내용 |
| --- | --- |
| A | 그대로. 연속 마킹은 분석에서 묶는다(예: 2초 안의 마킹은 하나로) |
| B | **눌림 확인만** — 버튼이 0.3초 밝아졌다 돌아온다. 화면의 다른 곳 · 소리는 바뀌지 않는다. 우 4 전부 같은 확인 |
| C | 마킹 표시를 남긴다(시간축에 점 등) — 마킹이 쌓이는 것이 보이면 *모으기*가 된다. 권하지 않는다 |

권고 **B.** 로그 · 스냅샷은 그대로라 분석에 영향이 없다.

## 결정과 조치 (09.29 · R-012)

D15 ③ **넣는다.** 안 B 적용 — 우 4 전부 눌리면 300 ms(`PRESS_ACK`) 밝아졌다 돌아온다. 소리 · 다른 화면 변화 없음. 로그 · 스냅샷 그대로. 데스크톱 `P20`에서 확인.
