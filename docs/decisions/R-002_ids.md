# R-002 — id 생성 규칙

| | |
| --- | --- |
| 날짜 | 2026-09-22 |
| 상태 | 승인 |
| SPEC | §4 (`id: string`) · §10 예시 `n81` `l2` `s12` |
| 코드 | `src/model.ts` `nextId` · `src/log.ts` `snapshot` |

## 정한 것
접두사 + 세션 내 1부터 증가하는 정수. 노트 `n`, 라벨 `l`, 칩 `c`, 스냅샷 `s`. 캔버스는 `n: number` 일련번호(1부터). 세션(페이지 로드) 안에서만 유일하다 — 새로고침 복구(2단계 `session.resume`)에서는 로그의 마지막 번호에서 이어 센다.

## 왜
SPEC 예시와 같은 모양이고, 사람이 로그를 읽을 때 순서가 보인다. UUID는 읽기 어렵고 얻는 것이 없다.
