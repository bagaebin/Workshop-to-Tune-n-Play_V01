## 관찰

- 사용자 3 — *"1단계와 2단계를 넘기는 순간을 사용자가 인지할 수 없으며, 2단계에 잠금된 기능이 무엇인지 알 수 없어 상태 변화를 명확하게 인지할 수 없습니다."*
- 사용자 6 — *"2단계에서 어떤 버튼을 눌러도 반응이 되지 않습니다."* → 로그상 **구간 2 전(hold)** 55초 동안의 접촉이다. 진행자(= 사용자)가 [구간 2 시작]을 누르기 전이라 설계대로 멈춰 있었다. [구간 2 시작] 뒤(3'31"~)에는 슬롯 접촉 15건이 전부 acted:true
- 이번 잠금은 **mat = blank**(pn_margin 0.0002 — 근거 약함). 빈 면 잠금은 사라지는 슬롯이 없고 *"재료를 먼저 놓아야 면이 반응한다"* 는 규칙이라 화면에 아무 표시가 없다

## 판단

셋이 겹쳐 있다.

| | 설계 의도 | 점검에서 드러난 것 |
| --- | --- | --- |
| 구간 전환 | 화면은 말하지 않고 **진행자가 말한다** — "여기까지 할게요" · 구두 확인 · "○○만 빼고 …" · [구간 2 시작] | 혼자 점검하면 말하는 사람이 없어 전환이 안 보인다. 실전에서는 진행자가 있다 |
| 잠긴 것 | 슬롯이 **사라진다**(D11). 무엇이 잠겼는지는 진행자의 과제문 "○○만 빼고"가 말한다 | 빈 면 잠금은 사라지는 것이 없다 |
| 멈춘 화면(hold) | 진행자가 말하는 동안 참여자가 조작하지 못하게 | 멈춘 이유가 화면에 없다 |

## 안

| # | 내용 | 비용 |
| --- | --- | --- |
| A | 그대로. 진행자 스크립트가 전환을 맡는다 (8-4 · 8-5 문장). 시트에 *"참여자 화면은 멈춰 있다"* 문구만(했다) | 0 |
| B | 구간 2 시작 때 **잠긴 슬롯 자리가 300 ms 동안 밝았다 사라진다** — 무엇이 없어졌는지 눈으로 한 번 | 30분. 빈 면 잠금에는 여전히 표시할 것이 없다 |
| C | **빈 면 잠금을 없앤다** — `candidates`에서 mat=blank를 빼거나, blank가 뽑히면 alt(다른 축)로 간다 | 잠금식 변경. D11 · D14 문서 · chain.py |
| D | 멈춘 화면(hold)에 흐린 막을 씌운다 | 15분. 글자 없음 |
