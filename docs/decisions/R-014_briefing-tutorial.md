## 무엇을 정하나

기능 소개(`phase:briefing`)를 진행자 낭독이 아니라 화면이 맡는다.

| # | 결정 (사용자) | 구현 |
| --- | --- | --- |
| 가 | 동작을 해야 [다음]이 켜진다 | 단계마다 기다리는 로그 사건 하나. 진행자는 시트 [이 단계 넘기기] |
| 나 | 진행자는 읽지 않는다 | 여는 말 한 문장만. 시트에 진행 · 경과 · 단계별 ●/○ |
| 다 | 동작 하나에 한 단계 | 15문장 → **34단계** ([단계표](../spec/15_briefing-steps.md)) |
| 라 | 시간 상한 없음 | 시트에 경과 / 7:00 |
| 마 | 마킹은 누르지 않아도 넘어간다 | `mark` · `end`는 조건 없음 |

## 왜

- 진행자 편차가 없어진다 — 전원 같은 문장 · 같은 화면
- V1.0 §7-1 *알고도 안 썼다*의 전제(소개에서 한 번 눌러봤다)가 로그(`intro.met`)로 확인된다

## 지키는 것

판정하지 않는다(칭찬 · 체크 없음) · 시범을 보이지 않는다 · 소개가 끝나면 화면에 글자가 남지 않는다.

## 함께 고친 것

- **노트 손잡이를 끝의 바깥쪽으로** — 기본 길이(≈38 px) 노트를 선택하면 양 끝 손잡이가 몸통을 덮어 옮길 수 없었다. 손잡이 영역을 바깥 20 px + 안쪽 0~8 px(긴 노트만)로. R-013 ⑥의 보정

## 되돌리는 방법

`BRIEFING_BANNER = false` → 띠 없음, 진행자 낭독. 또는 커밋 `dab0247`.
