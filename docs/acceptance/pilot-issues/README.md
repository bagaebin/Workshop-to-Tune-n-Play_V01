# pilot-issues/ — 파일럿 회차에서 발견한 이슈

09.26 자가 파일럿(과 그 뒤 세션)에서 본 문제를 **하나에 하나씩** 적는다. 형식은 [_template.md](_template.md). 파일 이름 `PI-001_짧은-제목.md`, 번호는 순서대로.
회차 하나의 관찰은 `_draft/YYYY-MM-DD_pilotN.md`(회차 기록)에 모아 적고, 거기서 이슈를 골라 PI 파일로 나눈다.

## 왜 따로 두나

- 파일럿의 산출은 셋이다 — 수용 테스트 결과([checklist.md](../checklist.md)) · 상수 교정([pilot-calibration.md](../pilot-calibration.md)) · **고쳐야 할 것**. 셋째는 표 한 줄로 안 끝나서 파일이 필요하다
- 이슈마다 **성격**을 가른다 — 버그는 코드, 상수는 교정표, 설계 빈칸은 `decisions/R-번호`, 상위 문서 정정은 볼트. 어디로 보낼지가 정해져야 09.28 전에 닫힌다
- `chain.py` 줄이나 `seq`를 근거로 남겨 두면 세션 뒤 분석에서 같은 자리를 다시 볼 수 있다

## 적는 법

1. `_template.md`를 복사해 `PI-00N_제목.md`
2. 표의 여섯 칸을 먼저 채운다 — 특히 **심각도**와 **세션 전 필수**
3. 위 색인에 한 줄 추가
4. 고치면 「조치」 표에 커밋 해시(또는 문서)를 적고 상태를 바꾼다. 파일은 지우지 않는다
