## 관찰

```
✘ idle 재계산 1건 = 로그의 seg 1 idle 2건
seq 104 text.open  t 253 080
seq 105 text.commit 'hello 안녕하세요'  dur 24 924  edits 49
seq 107 idle dur 28 145   ← 25 s 동안 타이핑했다
```

키보드 입력은 `touch.*`가 아니라서, 적기 구간을 열린 구간으로 두지 않으면 그대로 정지가 된다. 재생(`play`)과 마이크(`mic`)는 구간을 열고 있었는데 **적기만 빠져 있었다.** 검사 스크립트(PI-002 수정본)는 규칙대로 셌고 앱이 틀렸다.
