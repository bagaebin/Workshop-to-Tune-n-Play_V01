# PI-009 — 시간축 띠에 놓은 라벨을 옮기거나 지울 수 없다

| | |
| --- | --- |
| 날짜 · 회차 | 2026-09-23 · TEST2 |
| 발견 시점 | 구간 1 · 적기 |
| 관련 항목 | SPEC §6-7 · §5-1 `label:<id>` target |
| 심각도 | 경미 |
| 성격 | 설계 빈칸 — **사용자 결정 필요** |
| 상태 | 열림 |
| 세션 전 필수 | 아니오 (결정하면 예) |

## 관찰

사용자 — *"'hello 안녕하세요'를 적어 타임 영역 위로 올린 뒤 해당 텍스트의 위치를 수정할 수 없음."* 로그 — `text.place 'hello 안녕하세요' → axis` 뒤 `label:l1` 접촉이 `acted:false`.

## 판단

SPEC은 라벨을 히트 테스트 대상(`label:<id>`)으로 두었지만 **라벨에 걸리는 조작은 정하지 않았다.** 지금은 놓으면 끝이다. 면 위 라벨은 노트를 따라가므로(PI-006) 문제가 작지만, 띠 라벨은 노트가 없어 영영 그 자리다.

선택지 — ① 그대로(놓기는 되돌릴 수 없는 사건) ② 노트처럼 **끌어 옮기기 · 띠 밖으로 끌면 지우기**(`label.move` · `label.remove` 이벤트 신설). ②가 조작 규칙과 일관되지만 이벤트 스키마가 는다.
