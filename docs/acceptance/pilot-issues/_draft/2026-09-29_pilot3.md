## 재현

1. 비행기 모드를 켠 상태에서 이미지 에셋 5개 출력 확인
2. 이미지 에셋 추가 및 위치, 크기 조정
3. 사운드 에셋 출력 확인
4. 사운드 에셋 추가 시도

## 관찰

* 이미지 에셋 영역에 5개의 이미지가 첨부되어 있고 1칸의 이미지는 비어있음.
* 이미지 에셋의 위치를 조정하기 위해 이미지 중앙을 터치하면 새로운 노트가 추가됨 - 모서리를 선택해야 드래그 및 위치 조정을 할 수 있으나, 사용자가 바로 알기 어려움.
* 사운드 에셋을 1종만 확인할 수 있고 여러 개를 들어보고 비교할 수 없음.
* 사운드 에셋 1종이 재생되기만 하고 작업 영역 위에 추가할 수 없음.

- 사용자 인지
* 칩을 선택하고 크기를 조정하는 방법 및 조작 상태에 대한 인식을 할 수 없음.
* 터치로 선택(해제)할 수 있다는 인식을 할 수 없음.
* 전체 선택 버튼이 아이콘이 전체 선택을 의미한다는 것을 알 수 없음.

```
로그 없음 — 이 회차는 내보내기 파일을 받지 못했다.
데스크톱 재현(세션 P18, 같은 빌드): slot:mat.sound에서 면으로 끌어 놓기 → note.add src:material count 6 (2회 모두 성공)
```

## 기대

* 이미지 에셋의 개수는 5개로 고정, 영역을 5개에 맞도록 조정.
* 사운드 에셋을 여러 종 확인하고 미리 들어본 뒤, 해당 에셋을 연주하는 노트를 작업 영역에 추가할 수 있도록 함.

**공통 —** 1·2·3·5는 코드가 틀린 것이 아니라 *가르치지 않는 도구*에서 무엇이 발견되고 무엇이 안 되는지에 대한 관찰이다. Probe가 재려는 것이 바로 이것이라(v2.3 — 안 쓴 도구 · 비작동 접촉), **참여자에게도 같은 일이 일어날 것**이고 그것이 데이터가 된다. 다만 발견이 0에 가까우면 그 기능의 요인 자체가 결측이 되므로, 어디까지 도와줄지는 설계 결정이다.
