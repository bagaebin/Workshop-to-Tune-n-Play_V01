| | |
| --- | --- |
| 날짜 | 2026-09-22 |

## 무엇을 정하나
`n_before`에 무엇을 세는가. SPEC은 필드 이름만 준다.

## 정한 것
**현재 구간(seg)에서 이 마킹 전까지의 노트 조작 수** = `note.add` · `note.edit` · `note.remove` 건수 합. 구간이 바뀌면 0부터. 마킹 자체·재생·선택·상태 전환은 세지 않는다.

## 왜
F3 만족선의 주 지표가 *마킹 이후 조작 수 ÷ 이전 조작 수*(기능 명세 G11)라서 분모가 "만든 행위"여야 한다. 구간 2는 다른 과제이므로 구간별로 끊는다.

## 되돌리는 방법
로그에 `note.*`가 전부 남으므로 `chain.py`에서 다른 정의로 재계산할 수 있다. 필드값은 편의값이다.
