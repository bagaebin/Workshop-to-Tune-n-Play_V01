# PI-011 — 이미지 패널의 "여기 없다" 슬롯이 비어 있는 칸으로 읽힌다

| | |
| --- | --- |
| 날짜 · 회차 | 2026-09-29 · 점검 3 |
| 발견 시점 | 구간 1 · 이미지 패널 |
| 관련 항목 | SPEC §3-3 `absent` 슬롯 · §6-7 `image.absent` · 결정 D13 · N5 |
| 심각도 | 경미 (기능은 동작) — 다만 이 슬롯이 안 쓰이면 `image.absent` 데이터가 0이 된다 |
| 성격 | 설계 결정 — **사용자 결정 필요** |
| 상태 | 열림 |
| 세션 전 필수 | 예 (어느 쪽이든 전원 같은 빌드여야 한다) |

## 관찰 · 기대

사용자 — *"5개의 이미지가 첨부되어 있고 1칸의 이미지는 비어있음."* 기대 — *"이미지 에셋의 개수는 5개로 고정, 영역을 5개에 맞도록 조정."*

## 판단

이미지는 이미 5장으로 고정돼 있다. 여섯째 칸은 이미지가 아니라 **"여기 없다" 슬롯**이다(점선 100 × 100). 눌러서 *찾는 이미지가 없다*는 것을 글로 남기는 자리다. D13이 둔 이유 — 영상으로 떠올리는 사람이 맞는 이미지를 못 찾아 적기로 가면 **언어형으로 잘못 세게 된다.** 09.29 이미지 명세도 *"여기 없다 슬롯 — 바꾸지 않는다"*고 했다.

그런데 글자를 쓸 수 없어(N5) 점선 네모만으로는 뜻이 전달되지 않았다.

| 안 | 내용 | 잃는 것 |
| --- | --- | --- |
| A | **그대로.** 발견되지 않는 것도 관찰로 둔다. 회고에서 *"맨 아래 칸 보셨어요?"*를 묻는다 | 없음. `image.absent`가 0일 수 있다 |
| B | 슬롯 제거, 패널을 5장에 맞춤 | `image.absent` · D13의 오분류 방지. **볼트 결정 기록 · 개발 명세 수정 필요** |
| C | 유지하되 5장과 떨어뜨리고 모양을 바꾼다(구분선 · 다른 위치) — "여섯째 이미지"로 읽히지 않게 | 없음. 모양은 새로 정해야 한다 |

권고는 **A 또는 C.** B는 되돌리기 어렵다 — 세션이 시작되면 이 데이터는 다시 얻을 수 없다.
