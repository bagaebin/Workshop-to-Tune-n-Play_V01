## 관찰

사용자 — *"3번 이상 텍스트를 적을 수 없음."* 로그에는 `text.abort '' → 0.06 s 뒤 text.open`이 **9번** 있다. 모두 `slot:mat.blank` 접촉이다.

```
seq 94  text.abort chars 0 dur 1244  ← down slot:mat.blank
seq 96  text.open                    ← 같은 접촉
```

## 판단

입력 칸이 열린 상태의 접촉은 먼저 입력을 닫고(R-007 #3 — 그 접촉은 평소대로 동작), 그 접촉이 빈 면 슬롯이면 평소 동작인 "적기 열기"가 다시 일어났다. 슬롯을 다시 누르는 것은 참여자에게 "닫기"다.
