## 관찰

`"ua": "Mozilla/5.0 (Macintosh; Intel Mac OS X 10_15_7) … Version/26.6 Safari/605.1.15"` → `"os": "macOS 10.15"`. `device`는 터치 포인트로 `iPad`를 맞게 판정했다.

## 판단

iPadOS Safari는 데스크톱 UA를 보내고 OS 버전을 `10_15_7`로 고정한다. 페이지에서 iPadOS 버전을 알 방법이 없다. Safari 버전(26.6)만 믿을 만하다.
