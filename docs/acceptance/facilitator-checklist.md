# 진행자 준비 체크리스트 (SPEC §16 — 준비 화면에 그대로 들어간다)

`src/facilitator.ts`의 준비 화면(seg −1) 체크 항목 원문. 여기와 코드가 다르면 SPEC이 이긴다.

- [ ] 기내 모드 또는 Wi-Fi 끔 · 앱이 standalone으로 뜸
- [ ] 회전 잠금 켬 · **무음 모드 해제** · 알림 요약 끔
- [ ] 스피커 내장/유선 · 볼륨 70 %
- [ ] 마이크 권한 허용 · 레벨 미터에서 방 소음 아래로 임계 조정
- [ ] `pid` 입력 · 카메라 2대 녹화 시작 · 카메라 시계 확인
- [ ] **Guided Access 시작** (마지막)
- [ ] **[소리 확인]** — 짧은 소리가 나는지. 기기를 건네기 전 마지막 동작 (누르지 않으면 [시작]이 눌리지 않는다)
- [ ] [시작] → 플래시 → **자유 탐색 4분** → 화면 멈춤 → **기대 회고 3분**(시트 목록 · 안 누른 것 먼저) → [기능 소개 시작] **7분** → [화면 비우기] → 과제문 → [구간 1 시작] **10분** → *"여기까지 할게요"* → [구간 1 종료] → 구두 확인 · 잠긴 것 · 구간 2 과제문 → [구간 2 시작] **10분** → 회고

문장은 볼트 *2026-09-29_진행자 스크립트_V02* 3/5 · 4/5장이 정본이다. 시트에도 같은 문장이 나온다.

## 과제문 (전원 동일 — 실물 만들기와 글자 하나까지 같다)

> "떠오르는 것을 만들어 보세요. 정답도, 끝나는 기준도 없습니다. 완성하지 않으셔도 됩니다."

## 세션 중 원칙 (세션 계획 V03 §10)

- 개입 0. 질문받으면 *"편하신 대로 하세요"*만
- 2분 이상 완전 정지 시 **한 번만** — *"지금 무슨 생각 하고 계세요?"* (기록자가 시각을 적는다 — 마이크 span 제외용)
- 구간 1을 끊은 직후 — *"지금 멈추라고 해서 멈춘 건가요, 하실 만큼 하신 건가요?"*
- 구간 2 진입 시 — *"이번에는 ○○만 빼고 해보시겠어요? 나머지는 그대로예요. 10분입니다."* (○○는 시트에 나온다)
- 금지어 — GenUI · 발생형 AI · 바이브코딩 · 프롬프트
- 금지 행위 — 평가 반응 · **용도 설명**(기능 소개는 화면의 고정 문장 — 동작만. 진행자가 시연하지 않는다) · 탐색 중 조작법 설명
- 마킹 · 여기까지는 기준을 주지 않는다 — *"아무 때나 눌러도 되고 안 눌러도 됩니다"*

> 기능 명세 V1.0(09.29) 반영.
