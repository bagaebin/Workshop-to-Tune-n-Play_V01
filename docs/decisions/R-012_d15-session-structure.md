## 정한 것

1. **단계** — `seg`는 그대로 두고 봉투에 `phase`를 더한다. 기존 분석 코드(`seg` 기준)가 깨지지 않는다.

   | phase | seg | 화면 | 시작 | 끝 |
   | --- | --- | --- | --- | --- |
   | `prep` | −1 | 시트 | — | [시작] |
   | `circle` | 0 | 튜토리얼 원 | 플래시 | 시트 [① 자유 탐색 시작] |
   | `explore` | 0 | 전체 UI (여기까지 없음) | 시트 | `EXPLORE_LEN` 240 000 ms 또는 시트 [탐색 종료] |
   | `expect` | 0 | UI 동결 · 접촉 `acted:false` | 탐색 끝 | 시트 [③ 기능 소개 시작] |
   | `intro` | 0 | 전체 UI + 소개 띠 + 밝히기 | 시트 | 시트 [구간 1 시작] |
   | `create1` | 1 | 지금과 같음 | 시트 | 여기까지 / 상한 |
   | `create2` | 2 | 잠금 | 자동 | 타이머 |
   | `review` | 3 | 동결 | 자동 | — |

2. **빈 작업 공간** — 기능 소개 시작 때(`reason:intro`)와 구간 1 시작 때(`reason:create`) `workspace.reset {reason, from, to}`. 기대 회고 동안은 탐색에서 만든 것이 화면에 그대로 남아 있다(가리키며 물을 수 있게). 떠나는 캔버스의 `snapshot reason:phase`를 먼저 남기고, 캔버스 목록 · 칩 · 상태를 비운다(빈면 · OFF · 손). 구간 1은 항상 빈 캔버스 · 초기 상태에서 시작한다.
3. **체류 · 잠금 · 마킹** — 구간 1 이전의 접촉은 체류 · idle · 잠금 계산에 들어가지 않는다(`seg.start 1`이 기준점 — R-005 그대로). 창작 전 마킹은 로그에 남되 F3 집계 · `n_before`에서 제외(`seg ≥ 1`만).
4. **★ `SEG1_APPEAR` = 300 000 (5분)** — 결정은 "구간 1 10분"만 말한다. 이전 비율(8/15 ≈ 상한의 절반)에 맞춰 **가정**했다. 볼트에서 확정할 것.
5. **기대 회고 목록** — 시트가 탐색 중 `touch.down target:slot:*`에서 누른 슬롯(횟수 · 첫 시각)과 안 누른 슬롯을 **화면 배치 순서로** 보여 준다. 진행자가 하나씩 가리키며 묻는다.
6. **기능 소개** — (★ `mat.image` 문장이 「여기 없다」 슬롯을 알려 준다 — PI-011 결정 A와 부딪칠 수 있어 볼트 개정안 §4에 물음으로 올렸다) 단계 순서 = 좌 6(그 참여자의 화면 순서) → 서랍 3(화면 순서) → 면 위 동작(놓기 · 선택 · 고치기 · 사진 · (마이크)) → 마킹 · 남기고 새로 · 지우고 새로 · 여기까지. 문장은 `src/intro.ts`의 `TEXT` 고정. `intro.step {i, key}` · `intro.done`. 소개 중에도 기능은 평소대로 동작한다(참여자 손으로 한 번씩). 마이크 단계에서만 마이크 입력을 받는다.
7. **건너뛰기** — 시트는 어느 창작 전 단계에서든 [구간 1 시작 — 남은 단계를 건너뛴다]를 둔다(비상용). 건너뛴 회차는 `phase.start` 목록으로 드러난다. 본 세션에서는 쓰지 않는다.
8. **`?fast`** — 탐색 8 s · 나타남 5 s · 상한 10 s · 구간 2 10 s.

## 대안과 되돌리는 방법

`seg`를 늘리는 안(−1 · 0 · 1 · 2 …을 다시 매김)은 기존 로그 · chain.py · SPEC §10과 호환이 깨져 버렸다. 되돌리려면 시트에서 건너뛰기만 쓰면 이전 흐름(원 → 구간 1)과 같다 — 타이머 값은 상수 셋.
